# 皮肤病变面积测量小程序

## 项目状态
- 阶段：设计完成，等待实现
- 设计文档：`docs/design.md`

## 核心路径
微信小程序，路径 B（本地存储 + 测量规范）

## 核心流程
拍照 → 标定比例尺(0mm + 10mm) → 画病变轮廓多边形 → 展示面积(cm²) → 保存记录

## 技术要点
- 比例尺标定：两点法，10mm = 固定值
- 面积计算：Shoelace 公式
- 数据存储：微信本地存储，无强制账号
- 隐私：本地优先，截图分享用户主动触发
